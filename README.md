# Geometric Art Generator

A Python-based procedural generative art engine that creates abstract geometric compositions using controlled randomness.

## Features
- Randomized L, U and C geometric shapes
- Coordinate rotation and normalization
- Intersection detection
- Variable shape dimensions
- Configurable pattern density
- Customizable background and line colors

## Technologies
- Python
- Matplotlib
- Computational Geometry
- Procedural Generation

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/Geometric-Art-Generator.git
cd Geometric-Art-Generator
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
